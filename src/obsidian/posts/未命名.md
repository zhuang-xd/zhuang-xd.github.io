| 命令头          | 方向       | 说明                |
| ------------ | -------- | ----------------- |
| `imgrecset0` | App → 设备 | 同步当前 AI 识图质量档位    |
| `imgrecrsp0` | 设备 → App | 设置结果响应            |
| `imgreccap0` | App → 设备 | 触发 AI 识图，每次携带当前档位 |
| `imgrecdata` | 设备 → App | 图片数据包             |
| `imgreccan0` | App → 设备 | 取消设备端的识图会话        |
- 目前设备端不会将图片质量档位持久化到 NV，仅在运行内存中保存 `imgrecset0(level)` 同步的当前值；实际每次识图仍以 App 发出的 `imgreccap0(level)` 为准。因此 App 需要将质量档位保存到 `SharedPreferences`，并在每次识图请求中携带该档位。

### 2.1 设置项：智能图像识别模式

眼镜设置页面新增设置项：

```text
智能图像识别模式
```

点击后可选择传图质量档位：

| 档位  | App 文案 | 质量说明 |
| --- | ------ | ---- |
| 0   | 极速     | 低质量  |
| 1   | 普通     | 标准质量 |
| 2   | 细节     | 高质量  |
| 3   | 高清     | 最高质量 |

当前 demo 中配置在 `AiVisionSettings.java`：

```java
public static final int LEVEL_FAST = 0;
public static final int LEVEL_NORMAL = 1;
public static final int LEVEL_DETAIL = 2;
public static final int LEVEL_HD = 3;
public static final int DEFAULT_LEVEL = LEVEL_NORMAL;
```

当前 demo 将档位保存在 App 本地 `SharedPreferences`：

```java
public static final String PREFS_NAME = RecordingTimeActivity.PREFS_NAME;
public static final String KEY_AI_VISION_LEVEL = "ai_vision_level";

public static int getLevel(Context context) {
    return normalizeLevel(getPrefs(context).getInt(KEY_AI_VISION_LEVEL, DEFAULT_LEVEL));
}

public static void setLevel(Context context, int level) {
    getPrefs(context).edit().putInt(KEY_AI_VISION_LEVEL, normalizeLevel(level)).apply();
}
```
